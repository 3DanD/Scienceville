Политика конфиденциальности мобильного приложения «Наукоград: Сложение»

Дата вступления в силу: 12.10.2025

Настоящая Политика конфиденциальности описывает, какие данные получает и как их использует разработчик приложения «Наукоград: Сложение» (далее — Приложение).

1. Общие положения

Индивидуальный предприниматель Селянин Андрей Владимирович, ОГРНИП 320392600002640 (далее - Разработчик) уважает право пользователей на конфиденциальность и стремится обеспечить защиту информации, получаемой в процессе использования Приложения. Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

2. Сбор и использование данных

Приложение не запрашивает и не собирает персональные данные пользователей (имя, адрес, телефон и т.п.).

В Приложении используются сторонние сервисы аналитики и диагностики:

  • Firebase Crashlytics (Google LLC) — для сбора технической информации об ошибках и сбоях (модель устройства, версия ОС и т.п.);
  • AppMetrica (Яндекс) — для анализа анонимной статистики использования Приложения (длительность сессий, действия пользователей, география установок).

Эти данные используются исключительно для улучшения качества работы Приложения и не позволяют идентифицировать конкретного пользователя.

3. Передача данных третьим лицам

Собранные данные передаются только перечисленным выше сервисам. Разработчик не продаёт и не передаёт данные другим организациям.

4. Срок хранения данных

Собранные данные хранятся бессрочно.

5. Отказ от сбора данных

Если Вы хотите прекратить передавать данные Разработчику, просто удалите Приложение.

6. Безопасность

Все данные передаются по защищённым каналам (HTTPS). Доступ к ним ограничен и используется только для статистического анализа.
